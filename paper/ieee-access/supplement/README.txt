Michalczak and Filip Kruzel.

PRIMARY ANALYSIS
700 canonical records in 70 cells, ten records per cell. Native Android is
included only as a descriptive reference. Forty Legacy-New endpoint comparisons
are performed within devices. Calls and frames within one run are not replicate
experiments. Exact two-sided Mann-Whitney permutation tests enumerate all 184756
label assignments using average ranks for ties. Holm correction is primary within
each RQ over both devices. BH per RQ and Holm over all 40 tests are sensitivity
analyses. Bootstrap intervals are the deterministic 100000-resample pointwise
percentile intervals generated by the reference pipeline. They are not simultaneous
confidence intervals. Test inference assumes exchangeable independent runs;
incomplete order and environment records limit that premise.

ACQUISITION METADATA
acquisition_metadata.json records experimenter-reported device/build settings and
the expanded acquisition protocol. The Pixel 4a Android version and fingerprint
are reported acquisition metadata, not inferred from current device specifications.
The expanded Moto S1-S3 protocol specified alternating or randomized architecture
order and cooling breaks. Per-run order and temperature logs are unavailable, so
randomization, balancing, and thermal equivalence cannot be verified. The
s4_series_selection section identifies the two replaced Moto scalar records and
the two full Pixel array series replaced after fresh application builds. It also
records that numerical selection thresholds, a prospective replacement rule, and
complete rebuild commands are unavailable. This metadata file does not modify
the immutable v1.0.4 reference/ snapshot or any numerical result.

RESULT FILES
primary_contrasts.csv: exact tests, effects, intervals, RQ-wise Holm/BH, all-40
Holm, and explicitly named reference Monte Carlo p-values for provenance.
canonical_inventory.csv: the 70 canonical cells.
s4_initial_series_contrasts.csv: all 12 S4 comparisons after jointly restoring
the initial Moto scalar and Pixel payload-1/payload-10 series. Derived throughput
is recomputed from counts/durations and rounded to operations/s. Series are not
pooled. Reported Holm/BH corrections apply to these 12 alternative tests.
s4_remeasurement_sensitivity.csv: the three affected comparisons.
s4_unrounded_throughput.csv: all 12 canonical S4 comparisons using unrounded
count/duration ratios. The file reports medians and tests, not bootstrap intervals.
verification.json: counts, dependency versions, and verification outcomes.
reference_sha256.json: hashes of the reference inputs, scripts, and archived results.

BOUNDARIES
This is computational reanalysis of existing observations, not new phone testing.
Exact tests do not repair acquisition-order, selection, thermal or build confounds.
The separate Pixel scalar validation series is never pooled with primary data.
Current source-level correctness utilities do not prove their presence in every
historically measured APK. Software, traces and prospective acquisition guidance
are available in the cited upstream artifact. The main article does not claim
present-day framework rankings or identify a unique internal causal mechanism.
